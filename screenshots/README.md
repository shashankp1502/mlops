# Screenshots checklist

CLI-based verification output is already captured here as text
(`k8s_deployment_verification.txt`, `monitoring_verification.txt`) —
generated by actually running the deployment end-to-end on Minikube.

For the final written report, add real GUI screenshots (PNG) of:

- [ ] `docker ps` / `docker images` showing the built `heart-disease-api` image and running container
- [ ] GitHub Actions run — all 4 jobs (lint, test, train, docker) green
- [ ] GitHub Actions `train` job log showing both models' metrics
- [ ] `kubectl get pods,svc -n heart-disease` (2/2 heart-disease-api replicas Running)
- [ ] Browser hitting `/docs` (FastAPI Swagger UI) and a live `/predict` call
- [ ] Prometheus UI (`http://<prometheus-url>/targets`) showing `heart-disease-api` target as **UP**
- [ ] Grafana dashboard "Heart Disease API - Overview" with live data (make a few /predict calls first so the graphs aren't empty)
- [ ] MLflow UI comparing the Logistic Regression vs Random Forest runs

Naming convention: `0X_description.png` (e.g. `01_docker_build.png`,
`02_github_actions_pipeline.png`, `03_k8s_pods.png`, `04_grafana_dashboard.png`).
